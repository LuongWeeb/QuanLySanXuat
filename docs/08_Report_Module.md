# Reporting & Dashboard Module

## Mục tiêu

Phân hệ Reporting & Dashboard cung cấp báo cáo và dashboard theo thời gian thực.

## Phạm vi
- Dashboard Realtime
- Inventory Dashboard
- Production Dashboard
- KPI Dashboard
- Bottleneck Analysis
- Inventory Reports
- Production Reports
- Quality Reports
- Cost Reports
- Lot Traceability Reports
- Export Excel/PDF

## Dashboard
- Tổng Work Order
- Tiến độ sản xuất
- Tồn kho
- KPI
- Cảnh báo tồn kho

## Báo cáo
- Nhập-Xuất-Tồn
- Sản xuất
- Chất lượng
- Giá thành
- Truy vết Lot
- Bottleneck

## Business Rules
- Dashboard cập nhật realtime.
- Báo cáo chỉ đọc.
- Truy vết dùng LotGenealogy.
- Giá thành gắn với Work Order.

## AI Notes
Reporting tổng hợp dữ liệu từ Warehouse, Production, QC và Traceability.
