# Warehouse & Manufacturing Execution System (WMS + MES)

> AI Documentation Index

## Giới thiệu

Bộ tài liệu này được tái cấu trúc từ PRD gốc nhằm giúp các AI Coding Assistant (ChatGPT, Claude, Cursor, Windsurf, Roo Code, Antigravity...) nhanh chóng hiểu kiến trúc, nghiệp vụ và quy tắc của hệ thống.

Mục tiêu là giảm thời gian đọc PRD và tăng chất lượng sinh mã nguồn, phân tích nghiệp vụ và thiết kế.
